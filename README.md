# BOOTCAMP-0825-FRONTEND-REACT-NTT-MARISELIS
Proyecto de Bootcamp React JS NTT DATA
# Se ha implementado un pequeño ecommerce tomando como referencia el API de dummyjson.com, se ha usado useContext, useEffect y useState como hooks en el desarrollo.
# En la estructura de carpetas se intenta mantener separadas las responsabilidades de cada componente que hace vida en la app. En proxy se hacen las consultas al API, en components se encuentran los componentes de la aplicacion, en routes el enrutamiento o redireccion de vistas y en pages la vista principal del proyecto.
# Para levantar el proyecto localmente:
1. Tener instalado Node.js
2. Instalar las dependencias del proyecto con el comando "npm install" en la carpeta raiz del proyecto.
3. Ejecutar el comando "npm run dev" en la raiz del proyecto, copiar el link localhost y pegarlo en el navegador.
